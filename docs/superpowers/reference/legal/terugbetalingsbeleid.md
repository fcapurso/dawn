# Terugbetalingsbeleid

> Baseline captured 2026-07-02 at /policies/refund-policy; this version replaces the outdated casual text with a plain-language summary consistent with the Algemene voorwaarden. See git history for the untouched baseline.

Ben je toch niet helemaal gelukkig met je aankoop? Bij fysieke producten heb je een wettelijk herroepingsrecht van 14 dagen.

Je meldt je herroeping het makkelijkst via ons herroepingsformulier (zie de pagina Herroeping); je krijgt meteen een ontvangstbevestiging. Je stuurt de producten binnen 14 dagen terug, op eigen kosten.

Let op: zeep en badproducten zijn hygiene- en vochtgevoelig. Zijn ze gebruikt of aan vocht blootgesteld, dan kunnen wij ze niet opnieuw verkopen en kan de waardevermindering oplopen tot het volledige bedrag, dat we met je terugbetaling verrekenen.

De volledige voorwaarden, en de manier waarop wij terugbetalen, vind je in onze Algemene voorwaarden.
